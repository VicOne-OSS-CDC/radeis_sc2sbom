<objective>
Add a fallback mode to the lexical scanner so that C/C++ repositories with no package
manifests (e.g. the Juliet test suite) are still scanned for CWE findings.

Purpose: `component_dirs` is only populated by C/C++ manifest parsers. Pure source trees
like Juliet have no CMakeLists.txt or .pc files, leaving component_dirs empty and producing
zero findings despite 54k+ .c files.

Output:
- `has_c_cpp_files(root, max_depth)` helper in cwe_scanner.rs (pub, shallow WalkDir)
- Fallback block in main.rs: when component_dirs is empty after extraction, probe root;
  if C/C++ files exist, insert `(project_name, "C/C++") -> scan_root`
- Unit test: empty component_dirs + temp dir with a .c file -> fallback entry inserted
</objective>

   ```rust
   pub fn has_c_cpp_files(root: &Path, max_depth: usize) -> bool {
       WalkDir::new(root)
           .max_depth(max_depth)
           .follow_links(true)
           .into_iter()
           .filter_map(|e| e.ok())
           .any(|e| e.file_type().is_file() && is_c_cpp_source(e.path()))
   }
   ```

```rust
// Phase 11 fallback: for repos with no C/C++ manifests (e.g. Juliet test suite),
// synthesise a single entry covering the entire scan root so the lexical scanner runs.
#[cfg(feature = "internal")]
if component_dirs.is_empty()
    && crate::vulnerability::has_c_cpp_files(&args.path, 3)
{
    let project_name = args.path
        .file_name()
        .and_then(|n| n.to_str())
        .unwrap_or("project")
        .to_string();
    component_dirs.insert((project_name, "C/C++".to_string()), args.path.clone());
}
```
