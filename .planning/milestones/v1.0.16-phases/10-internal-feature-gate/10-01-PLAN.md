## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Information Disclosure | Public binary contains vulnerability scanning code visible via `strings`/`--help` | mitigate | Module-level `#[cfg(feature = "internal")]` on `pub mod vulnerability;` in `src/lib.rs` and `mod vulnerability;` in `src/main.rs` ensures the entire `src/vulnerability/` subtree is excluded from compilation when `internal` feature is absent |
| T-10-02 | Information Disclosure | Optional dep `reqwest` linked into public binary leaks network-capable code surface | mitigate | `reqwest = { optional = true, ... }` + `internal = ["dep:reqwest"]` ensures reqwest is not in the public build's link graph |
| T-10-03 | Tampering | Developer accidentally constructs Dependency with explicit `vulnerabilities:` field, leaking field name | accept | Plan 02 migrates all construction sites; this plan only sets up gates. Compile failure is the warning signal |
