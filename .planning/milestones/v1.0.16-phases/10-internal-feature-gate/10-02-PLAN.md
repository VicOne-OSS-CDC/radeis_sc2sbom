**Reference migration pattern (copy this shape):**

BEFORE:
```rust
Dependency {
    name: pkg_name,
```

AFTER:
```rust
Dependency {
    name: pkg_name,
    version,
    ecosystem: "cargo".to_string(),
    source: DependencySource::LockFile,
    component_path: None,
    /* ... other fields (only if all needed) ... */
    ..Default::default()
}
```
