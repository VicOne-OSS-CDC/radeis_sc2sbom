         - Get `cond = node.child_by_field_name("condition")` (for_statement: middle child via field name `"condition"`).

       - If `node.kind() == "expression_statement"`:
         - Take the first named child. If it is `binary_expression` AND its operator (`node.child_by_field_name("operator")` text) is `"=="` → push SastFinding { cwe_id: 482, line of node }
       - Recurse via fresh-cursor pattern.

    3. `fn check_func_ptr_null_compare(node, src, path, component_name, component_ecosystem, findings)`

         - push SastFinding { cwe_id: 480, line of node }
       - Recurse via fresh-cursor pattern.
