<objective>
Wave 2: introduce two new `ArgCheck` enum variants (`FixedSizeBufferWithoutSizeArg(u8)` for CWE-126; `SizeArgIsMultiplication(u8)` for CWE-680), tighten `collect_pointer_declarators` so CWE-467 no longer fires on pointer-to-struct, and migrate CWE-535 from an over-broad `ArgAtIndex(0, &["stderr"])` rule to a dedicated `check_stderr_format_string()` visitor that requires arg 0 == `stderr` AND arg 1 is not a `string_literal`.

Purpose: Address the four high-FP CWEs whose fix requires *expression-shape* checks that pure function-list / AnyCall edits cannot express. Plan 01 (function-list edits) is a prerequisite because the CWE-780 and CWE-256 cleanups must precede this plan to avoid churn on the same table entries.

Output:
- Two new ArgCheck variants and their match arms in visit_node()
- CWE-126 split into two AST_CWE_RULES entries (strcat keeps FixedSizeBuffer; strncat uses FixedSizeBufferWithoutSizeArg(2))
- CWE-680 entry switched to SizeArgIsMultiplication(0)
- CWE-467: collect_pointer_declarators() skips struct/union pointer declarations
- CWE-535: ArgAtIndex entry removed from AST_CWE_RULES; new check_stderr_format_string() visitor added; called from apply_ast_rules()
- Unit tests covering each fix

        src: &[u8],
        path: &std::path::Path,
        component_name: &str,
        component_ecosystem: &str,
        findings: &mut Vec<SastFinding>,

                let fn_name = func_node.utf8_text(src).unwrap_or("");
                if fn_name == "fprintf" || fn_name == "vfprintf" {
                    if let Some(arg_list) = node.child_by_field_name("arguments") {
                        let mut cursor = arg_list.walk();
                        let args: Vec<Node> = arg_list.named_children(&mut cursor).collect();
                        let arg0_stderr = args.first()

                                component_ecosystem: component_ecosystem.to_string(),
                                file_path: path.to_string_lossy().into_owned(),
                                line: (node.start_position().row as u32) + 1,
                                source: SastSource::Ast,
                            });
                        }
                    }

        let mut cursor = node.walk();
        if cursor.goto_first_child() {
            loop {
                check_stderr_format_string(

                );
                if !cursor.goto_next_sibling() { break; }
            }
        }
    }
