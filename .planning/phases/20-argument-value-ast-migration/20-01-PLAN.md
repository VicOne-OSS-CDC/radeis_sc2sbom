<objective>
Migrate the CWE-295, CWE-319, and CWE-732 argument-value detection rules in the AST scanner from `ArgCheck::ContainsTokens` (which scans ALL args for tokens) to a new `ArgCheck::ArgAtIndex(u8, &'static [&'static str])` variant (which inspects one specific positional argument's AST subtree). Delete `ContainsTokens` from the enum. Close the wolfSSL gap by adding `wolfSSL_CTX_set_verify` to the AST rule table. Add 11 unit tests covering TP, FP guards, nested expression, and the umask kind-check guard.

Purpose: Positional scoping eliminates cross-arg false positives (e.g. CWE-732 `umask(0077)` will no longer fire because of an octal literal). The wolfSSL addition closes a coverage gap that would otherwise widen when Plan 02 removes the lexical fallback for these CWEs.

Output: A working AST scanner with the new `ArgAtIndex` variant, three migrated CWE rule groups, and a comprehensive AST test suite that protects against regression when the lexical-side cleanup ships in Plan 02.
</objective>

       /// single space-separated string. Used by ArgCheck::ArgAtIndex (D-02).
       /// Uses named_children to skip punctuation (commas, parens) — see RESEARCH.md Pitfall 2.
       fn collect_subtree_text(node: tree_sitter::Node, src: &[u8]) -> String {
           if node.child_count() == 0 {

           for child in node.named_children(&mut cursor) {
               let child_text = collect_subtree_text(child, src);
               if !child_text.is_empty() {
                   if !result.is_empty() {
                       result.push(' ');
                   }

               }
