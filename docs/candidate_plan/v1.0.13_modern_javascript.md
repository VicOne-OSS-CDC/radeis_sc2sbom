## Tasks

### Task 1: pnpm Support — pnpm-lock.yaml
**Files:** `src/parsers/npm.rs` (or new `src/parsers/pnpm.rs`)

**Supported Format:** YAML lockfile
```yaml
lockfileVersion: '6.0'
dependencies:
  express:
    specifier: ^4.18.2
    version: 4.18.2
packages:
  /express@4.18.2:
    resolution: {integrity: sha512-...}
    dependencies:
      accepts: 1.3.8
```

**Parser Function:**
```rust
pub fn parse_pnpm_lock(path: &Path) -> Result<Vec<Dependency>>
```

- Parse with `serde_yaml` (already available)
- Extract package names and resolved versions from `packages` section
- Distinguish direct (in `dependencies`) vs transitive
- Reuse existing `load_package_metadata_hybrid` for npm registry enrichment
- Set `ecosystem: "npm"` (pnpm uses the npm registry)

**CLI Flag:** `--scan-pnpm <BOOL>` (default: true)

**Estimated Effort:** 4-6 hours

---

### Task 2: Yarn v3+ (Berry) Support
**Files:** `src/parsers/npm.rs`

**Supported Format:** Yarn Berry lock file (v6+)
```
__metadata:
  version: 6

"express@npm:^4.18.2":
  version: 4.18.2
  resolution: "express@npm:4.18.2"
  checksum: sha512-...
```

**Parser Function:**
```rust
pub fn parse_yarn_berry_lock(path: &Path) -> Result<Vec<Dependency>>
```

- Detect Yarn version by checking for `__metadata` section (v3+) vs classic format (v1)
- Parse YAML-like format (Yarn Berry uses a custom YAML variant)
- Extract package name, version, checksum
- Set `ecosystem: "npm"`

**CLI Flag:** `--scan-yarn-berry <BOOL>` (default: true)

**Important:** Must not break existing Yarn v1 parsing in `npm.rs`

**Estimated Effort:** 4-6 hours

### Task 3: npm Workspaces Support
**Files:** `src/parsers/npm.rs`, `src/scanner/mod.rs`

**Supported Format:** package.json workspaces field
```json
{
  "workspaces": ["packages/*", "apps/*"]
}
```

**Function:**
```rust
pub fn detect_npm_workspaces(root: &Path) -> Vec<PathBuf>
```

- Read root `package.json` for `workspaces` field
- Resolve glob patterns to workspace package directories
- Ensure scanner visits workspace package.json files
- Deduplicate with existing hoisted dependencies from root lock file

**Estimated Effort:** 4-6 hours
