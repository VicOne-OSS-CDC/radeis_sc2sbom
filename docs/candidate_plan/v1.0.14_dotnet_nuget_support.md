## Executive Summary

This release adds **.NET/NuGet ecosystem support** with 4 file format parsers:
1. **packages.lock.json** (NuGet lock file — highest priority, exact versions + SHA512)
2. **packages.config** (Legacy XML format)
3. ***.csproj** (Modern .NET Core/5+ PackageReference format)
4. **Directory.Packages.props** (Central Package Management)

**Key Metrics:**
- New ecosystem: .NET/NuGet
- PURL format: `pkg:nuget/{package}@{version}`
- Expected coverage: 95%+ modern .NET, 80%+ legacy .NET Framework
- Total ecosystems: 26 (up from 25)

## Phase 1: .NET Parser Module

### Task 1: Core Parser — packages.lock.json
**Files:** New `src/parsers/dotnet.rs`

**Supported Format:** NuGet lock file (JSON)
```json
{
  "version": 1,
  "dependencies": {
    "net8.0": {
      "Newtonsoft.Json": {
        "type": "Direct",
        "requested": "[13.0.3, )",
        "resolved": "13.0.3",
        "contentHash": "HKkZ..."
      }
    }
  }
}
```

**Parser Function:**
```rust
pub fn parse_packages_lock_json(path: &Path) -> Result<Vec<Dependency>>
```

- Parse with `serde_json` (already in Cargo.toml)
- Extract: name, resolved version, type (Direct/Transitive), contentHash (SHA512)
- Map `type: "Direct"` → `is_direct: true`, `type: "Transitive"` → `is_direct: false`
- Set `ecosystem: "nuget"`

---

### Task 2: Legacy Parser — packages.config
**Files:** `src/parsers/dotnet.rs`

**Supported Format:** Legacy XML
```xml
<?xml version="1.0" encoding="utf-8"?>
<packages>
  <package id="Newtonsoft.Json" version="13.0.3" targetFramework="net48" />
</packages>
```

**Parser Function:**
```rust
pub fn parse_packages_config(path: &Path) -> Result<Vec<Dependency>>
```

- Parse with `quick-xml` (already in Cargo.toml)
- Extract: id → name, version, targetFramework (metadata)
- All dependencies are direct (no transitive info in this format)

---

### Task 3: Modern Parser — .csproj PackageReference
**Files:** `src/parsers/dotnet.rs`

**Supported Format:** MSBuild XML
```xml
<Project Sdk="Microsoft.NET.Sdk">
  <ItemGroup>
    <PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
    <PackageReference Include="xunit" Version="2.4.2" PrivateAssets="all" />
  </ItemGroup>
</Project>
```

**Parser Function:**
```rust
pub fn parse_csproj_packages(path: &Path) -> Result<Vec<Dependency>>
```

- Parse with `quick-xml`
- Extract PackageReference elements: Include → name, Version → version
- `PrivateAssets="all"` → dev/test dependency hint

---

### Task 4: Central Package Management — Directory.Packages.props
**Files:** `src/parsers/dotnet.rs`

**Supported Format:** MSBuild XML (version centralization)
```xml
<Project>
  <PropertyGroup>
    <ManagePackageVersionsCentrally>true</ManagePackageVersionsCentrally>
  </PropertyGroup>
  <ItemGroup>
    <PackageVersion Include="Newtonsoft.Json" Version="13.0.3" />
  </ItemGroup>
</Project>
```

**Parser Function:**
```rust
pub fn parse_directory_packages_props(path: &Path) -> Result<Vec<Dependency>>
```

## Phase 2: System Integration

### Task 5: Wire into Scanner + CLI
**Files:** `src/parsers/mod.rs`, `src/scanner/mod.rs`, `src/cli.rs`, `src/main.rs`

- Export parser functions from `mod.rs`
- Add file matching in `scan_directory()`:
  - `"packages.lock.json"` → `parse_packages_lock_json`
  - `"packages.config"` → `parse_packages_config`
  - Files ending in `.csproj` → `parse_csproj_packages`
  - `"Directory.Packages.props"` → `parse_directory_packages_props`
- Add CLI flag: `--scan-dotnet <BOOL>` (default: true)
- Pass flag through to scanner

### Task 6: PURL + Scope Classification
**Files:** `src/formats/spdx.rs`, `src/classifier/ecosystem.rs`

- Add PURL mapping: `"nuget"` → `pkg:nuget/{name}@{version}`
- Add scope extraction for .NET:
  - `PrivateAssets="all"` → Test/Development scope
  - `type: "Transitive"` from lock file → indirect dependency

### Task 7: Integration Tests
**Files:** New `tests/parser_tests/dotnet_tests.rs`

- Test fixtures for all 4 file formats
- Verify PURL generation
- Verify scope classification
